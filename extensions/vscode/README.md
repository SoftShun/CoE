# 🚀 AXCode for VS Code — User Guide

AXCode is your **AI code agent** in VS Code using on SOC.  
Chat, refactor, autocomplete, and explore your codebase without leaving your editor.

---

## ⚡ Quick Start

- Open AXCode panel: **Ctrl+L** / **Cmd+L**
- Add selection to chat: **Ctrl+Shift+L** / **Cmd+Shift+L**
- Start chatting with AI about your codebase.

---

## 💡 Features

- **Chat with AI** about your project or files
- **Edit and refactor code** with natural language
- **Autocomplete** code with toggle and force options
- **Context-aware**: add selections, files, or entire repo
- **Debug with AI** in the terminal
- **History & logs** to review past sessions

## ⌨️ Keyboard Shortcuts

| Action                            | Windows/Linux        | macOS               |
| --------------------------------- | -------------------- | ------------------- |
| Open AXCode panel                 | Ctrl+L               | Cmd+L               |
| Add selection to chat (keep chat) | Ctrl+Shift+L         | Cmd+Shift+L         |
| Edit highlighted code             | Ctrl+I               | Cmd+I               |
| Exit edit mode                    | Esc                  | Esc                 |
| Accept code change (Diff)         | Shift+Ctrl+Enter     | Shift+Cmd+Enter     |
| Reject code change (Diff)         | Shift+Ctrl+Backspace | Shift+Cmd+Backspace |
| Undo reject (Diff)                | Ctrl+Z               | Cmd+Z               |
| Accept vertical diff block        | Alt+Ctrl+Y           | Alt+Cmd+Y           |
| Reject vertical diff block        | Alt+Ctrl+N           | Alt+Cmd+N           |
| Apply code from chat              | Alt+A                | Alt+A               |
| Debug terminal                    | Ctrl+Shift+R         | Cmd+Shift+R         |
| Open in new window                | Ctrl+K, Ctrl+M       | Cmd+K, Cmd+M        |
| Toggle autocomplete on/off        | Ctrl+K, Ctrl+A       | Cmd+K, Cmd+A        |
| Force autocomplete                | Ctrl+Alt+Space       | Cmd+Alt+Space       |
| Toggle Next Edit                  | Ctrl+K, Ctrl+N       | Cmd+K, Cmd+N        |
| Accept Next Edit suggestion       | Tab                  | Tab                 |
| Hide Next Edit suggestion         | Esc                  | Esc                 |
| Accept Jump suggestion            | Tab                  | Tab                 |
| Reject Jump suggestion            | Esc                  | Esc                 |
